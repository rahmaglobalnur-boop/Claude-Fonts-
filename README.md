# Claude Fonts

Коллекция фирменных и рабочих шрифтов для дизайн-систем NUR / Claude.

## Семейства

**Брендовые:**
- `Space Grotesk` — основной дисплей/UI шрифт
- `Strogo` — display/heavy, силовые заголовки (NUR Design System)
- `Axon` — body/UI текст (NUR Design System)

**Рабочая библиотека:**
Ammar, Adallyn, Butler, Montserrat, Mansfield, Neue Montreal, TT Interphases Pro Mono, Grotesk, JetBrains Mono, Geist, Geist Mono, Instrument Sans, Inter, Satoshi, Book Antiqua, Engagement

## Лицензии

Часть семейств распространяется по SIL Open Font License (Space Grotesk, Montserrat, JetBrains Mono, Geist, Geist Mono, Inter, Instrument Sans, Grotesk). Остальные (Satoshi, Neue Montreal, Butler, Mansfield, TT Interphases Pro Mono, Ammar, Adallyn, Book Antiqua, Engagement, Strogo, Axon) распространялись как триальные/коммерческие или без явной лицензии — репозиторий приватный, для внутреннего использования в проектах NUR. Перед публичным/коммерческим использованием каждого шрифта из этой группы проверить лицензию у правообладателя.

## Синхронизация

Коллекция также зеркалирована в Notion (хаб «Claude Fonts») и локально в iCloud.
